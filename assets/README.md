# Assets

Place user-supplied files here.

## Required

- **`resume.pdf`** — Your resume. The site links to it via `assets/resume.pdf`
  from the "Download Resume" buttons in the Hero and Contact sections. Add this
  file so the download works; until then the link resolves to a normal 404 and
  the rest of the site keeps working.

## Optional

- **`favicon.svg`** — A site icon. If you add one, reference it from the
  `<head>` of `index.html` with a relative path, e.g.
  `<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">`.
